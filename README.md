# V-SHIELD

## Overview
V-SHIELD is an AI-powered real-time voice security platform designed to analyze live voice communication and detect potentially AI-generated, cloned, spoofed, or manipulated voices.

## Current Architecture
The project follows a decoupled client-server architecture with a React frontend and a FastAPI backend. 

## Technology Stack
- **Frontend**: React, Vite, TypeScript, Tailwind CSS
- **Backend**: Python, FastAPI, WebSockets
- **AI/ML**: PyTorch, Torchaudio, Librosa (Future phases)
- **Database**: PostgreSQL, SQLAlchemy (Future phases)

## Current Phase
**Phase 1 — Project Foundation**
Sets up the scalable, modular full-stack architecture including frontend structure, backend REST and WebSocket APIs, and placeholder AI/ML directories without implementing the deepfake detection model.
